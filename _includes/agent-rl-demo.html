01 / Embodied VQA

Where is the target, relative to the hand?

One scene supports questions about image location, relative height, and where to move. The model receives RGB views and measured robot state; the simulator supplies reference labels for training.

02 / VQA reinforcement learning

Turn spatial questions into training feedback

  1. Sample answersThe student proposes several answers for the same observation.
  2. Check against the sceneSimulator labels score spatial accuracy, beyond the answer’s format.
  3. Update and re-evaluateRL uses the scored answers; agent replay helps retain tool-use behavior.

VQA reward and closed-loop task success are evaluated separately. Better answers alone do not establish better robot execution.

03 / Short skills toward longer tasks

Break “put the apple in the bowl” into testable skills

Local objectives make it possible to test alignment, grasping, and placement separately before studying their composition over a full task.
