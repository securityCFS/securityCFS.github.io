How StaRUA learns to reach

  1. Spatial supervised fine-tuningThe model rehearses demonstrated tool calls and answers questions about the same scene. A fingertip offset is expressed in the arm coordinates it will use to move.
  2. Embodied VQA reinforcement learningThe model tries several answers about distance, fingertip clearance, or the target’s position in a wrist image. A simulator verifier scores each answer against the recorded state.
  3. Pre-grasp skill learningThe robot practises approaching and coming to a steady hold over the target. Pushing the object out of place costs it the reward, even if its fingertips end up close.
  4. Full-task reinforcement learningThe agent acts through complete episodes. It receives feedback for reaching subgoals and finishing the task, including what happens after it closes the gripper.
