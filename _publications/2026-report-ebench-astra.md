This interactive report evaluates GPT-6-Astra as an embodied control policy on EBench. It compares task-level performance with VLA and world-action policies and examines in-context learning, task composition, recovery, and precision-sensitive manipulation through recorded executions.

The public web report contains the evaluation protocol, results, and case studies. Its linked arXiv technical report is marked as coming soon; the available web report is linked above.
