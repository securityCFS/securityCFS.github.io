This report evaluates GPT-6-Astra on EBench under two configurations: direct robot control, and an agent harness that can invoke post-trained VLA or world-action policies. It examines performance across manipulation tasks, along with delegation, recovery, and precision-sensitive execution.

The project page presents the earlier direct-control web report, titled “How Far Does a Frontier Agent Get as an Embodied Policy?”, with results and case studies. The arXiv report also studies the policy harness.
